# Recommended GitHub Topics

The following topics are recommended for the GitHub repository. They are
intended to position KVFlow as an AI infrastructure and systems research
project without drifting into generic or hype-oriented tagging.

- ai-infrastructure
- llm-inference
- inference-systems
- kv-cache
- memory-hierarchy
- systems-research
- runtime-systems
- systems-architecture
- long-context
- hbm
- cxl
- dram
- sram
- prefetching
- dma
- cache-management
- memory-orchestration
- inference-optimization
- serving-systems
- accelerator-research
- compression
- simulation

## Notes

- Keep topics lowercase and GitHub-topic friendly.
- Prefer systems and infrastructure terms over broad consumer AI terms.
- Avoid generic tags such as `ai`, and avoid hype-oriented or unrelated topics.
