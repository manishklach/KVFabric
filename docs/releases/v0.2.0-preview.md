# KVFabric v0.2.0-preview — Runtime API, Policy Comparisons, and Cost-Aware Modeling

This preview note documents the next stage of KVFabric research scaffolding.
It is intentionally framed as preview documentation for the repository’s
evolving architecture direction, not as a statement of production readiness.

## Included In This Preview

- conceptual runtime API sketch for a KV-aware control plane
- cost model proxy for rough `$ / token` tradeoff reasoning
- policy comparison mode
- synthetic sensitivity sweep workloads
- overlap model documentation
- roadmap maturity ladder

## Why This Matters

These additions strengthen the bridge between the simulator and the broader
architecture thesis. The repository is no longer only asking whether tiering
reduces HBM traffic. It is also asking:

- what runtime hooks would make KV orchestration explicit
- how policy choices differ under the same workload
- where tiering helps or hurts across context sizes
- how memory decisions relate to cost proxies

## Continued Limitations

- The simulator remains approximate and exploratory.
- Runtime APIs are conceptual only.
- The cost model is not a cloud pricing calculator.
- Policy comparisons are workload-sensitive and not benchmark claims.
- The overlap model is still a simplification of real asynchronous execution.

## Preview Scope

This preview should be read as research scaffolding for the next stage of the
project rather than as a production software milestone.
