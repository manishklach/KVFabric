# KVFabric v0.2.1 — Realistic Hardware Profiles, Trace Replay, and Improved Overlap Modeling

## Overview

KVFabric v0.2.1 strengthens the repository as a reproducible inference-memory
systems simulator rather than only an architecture thesis. This release
focuses on runtime-adjacent grounding, simulator realism, and validation.

## Included In v0.2.1

- CI pipeline for tests and experiment smoke checks
- markdown link checking
- realistic hardware profiles
- request-level JSONL trace replay support
- improved overlap modeling with hidden vs exposed latency
- matplotlib-based result figures
- runtime API implementation scaffolding
- expanded algorithmic tests

## Why This Matters

The repository now makes it easier to study:

- how workload shape changes residency pressure
- how hardware assumptions affect tier behavior
- when overlap hides memory movement
- how policies differ under the same workload

## Continued Limitations

- The overlap model remains approximate.
- There is still no GPU kernel execution.
- There is still no real DMA hardware or firmware.
- Trace replay is request-level, not full runtime telemetry.
- Runtime API code is scaffolding, not a production integration.
